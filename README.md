# 🌿 Gobro — West Bengal Tourism Platform

A complete travel platform for discovering 221 destinations across West Bengal,
with authentic Bengali festivals, food, hotels, transport, and AI travel assistant.

## What's inside

```
gobro/
├── frontend/    — React 18 + Vite + TypeScript + Tailwind v4
├── backend/     — Node.js + Express + PostgreSQL
└── DEPLOY_GUIDE.md  ← Read this first!
```

## Quick start

1. **Read DEPLOY_GUIDE.md** — full step-by-step deploy instructions
2. **Push to GitHub** — `git push` after copying frontend/ + backend/ to your repo
3. **Deploy backend on Render** — uses `backend/render.yaml` blueprint
4. **Update Netlify** — set `VITE_API_BASE` env var to your Render URL
5. **Add Gemini API key** — for real AI, get free at aistudio.google.com

## Features

- 🏔️  221 West Bengal destinations
- 🎉 12 authentic Bengali festivals with dates, vibes, food pairings
- 🍽️  17 Bengali dishes + 5 famous food streets
- 🏨 17 hotels & homestays linked to destinations
- 🚆 8 transport guides (Kolkata → each major place)
- 🤖 Multi-provider AI (Gemini → Groq → smart fallback)
- 💖 Wishlist, reviews, gamification, trip planner
- 📝 Blog, forum, community features
- 🛡️  Admin dashboard
